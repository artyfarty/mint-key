Add a secret

Write-only: a value can be set or replaced here, but never shown — nothing on this page decrypts. Storing a secret needs no YubiKey (it is encrypted to the recipients); only granting one does. To edit a value in place, use mintk secret edit <name> (or mintk i → Manage secrets).

Add a group

A path creates the whole branch. Empty groups are kept in groups:.

Changing a principal or deleting a scope stays in the terminal (mintk scopes edit / delete) — harder to hit by accident there.

Wipe minted identities

Deletes every session key and cert in sessions_dir. The next mint re-creates the key (and asks for a tap).

Revoke all secret grants

Wipes every live grant from tmpfs now instead of waiting for its TTL.

Register another key

Login is a tap on any key listed here (WebAuthn / FIDO2, touch only — nothing is stored on the key, so no PIN and no key slots used). The list lives in web-credentials.json. Lost every key? mintk web enroll prints a one-time link to register a new one.
